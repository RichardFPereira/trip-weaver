# TripWeaver

A collaborative trip planner, built step by step as a learning portfolio.

The architecture is not designed up front. It grows from the problems each increment reveals, and every significant decision is recorded in [`docs/adr`](docs/adr).

## How it is built
- The backend is written by hand. AI (Claude Code) acts as a mentor and reviewer.
- The frontend (Blazor) is AI-generated and reviewed by me.
- The rules are in [`AGENTS.md`](AGENTS.md).

## Status
